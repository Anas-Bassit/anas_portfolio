# Anas Portfolio

The frontend foundation for Anas Bassit's personal portfolio.

## Stack

React, Vite, TypeScript, Tailwind CSS, Motion, Lucide React, ESLint, and Prettier.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run format:check
```

## Production build

```bash
npm run build
npm run preview
```
